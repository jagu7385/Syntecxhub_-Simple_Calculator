# 🧮 Simple Command-Line Calculator

A simple and user-friendly **command-line calculator** built in Python.  
This project performs basic arithmetic operations such as **addition (+), subtraction (−), multiplication (×), division (÷)** and also includes a **clear function**.

The calculator accepts user input, validates it, handles errors like divide-by-zero, and provides a clean menu system for repeated calculations.



## 🚀 Features

- ➕ **Addition (+)**
- ➖ **Subtraction (−)**
- ✖️ **Multiplication (* or ×)**
- ➗ **Division (/ or ÷)**
- 🧹 **Clear function**
- 🔄 **Simple interactive menu**
- ✔️ **Input validation**
- ⚠️ **Divide-by-zero handling**
- 🧩 **Logic separated into functions for testability**
